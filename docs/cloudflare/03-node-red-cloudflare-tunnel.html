1. ตรวจสอบ Node-RED ก่อนเข้า Cloudflare

ไฟล์นี้ถือว่า Node-RED ถูกติดตั้งและตั้งค่าไว้แล้ว ขั้นนี้ตรวจเพียงว่า origin พร้อมสำหรับส่งผ่าน Cloudflare Tunnel

ตรวจ service:

systemctl status nodered.service --no-pager

ควรพบ:

Active: active (running)

ตรวจว่า Node-RED เปิด port 1880:

ss -lntp | grep 1880

ควรพบประมาณ:

0.0.0.0:1880

ทดสอบจาก Raspberry Pi:

curl -I http://localhost:1880

ควรได้:

HTTP/1.1 200 OK

ถ้ายังไม่ได้ติดตั้ง Node-RED หรือยังไม่ได้ตั้งค่า User Security ให้กลับไปทำที่ Node-RED MQTT ก่อน

ทดสอบจากเครื่องใน LAN:

หา IP ของ Raspberry Pi:

hostname -I

สมมติได้:

192.168.1.50

เครื่องอื่นใน LAN เปิด:

http://192.168.1.50:1880

จะเข้าสู่หน้า Node-RED

Login ด้วย Username/Password ที่กำหนดไว้

2. การเปิด Node-RED จาก Internet

ระบบ kathu ใช้ Cloudflare Tunnel ดังนี้:

รายการ ค่า
Tunnel name kathu
Tunnel UUID ตรวจค่าจริงด้วย cloudflared tunnel list

3. สร้าง DNS สำหรับ Node-RED

บน Raspberry Pi:

cloudflared tunnel route dns kathu node-red.vodun.cc

แนวคิดคือ:

node-red.vodun.cc
        │
        ▼
Cloudflare
        │
        ▼
Tunnel: kathu

4. เพิ่ม Node-RED ใน Cloudflare Tunnel Config

เปิด:

sudo nano /etc/cloudflared/config.yml

ตัวอย่าง configuration:

tunnel: TUNNEL_UUID
credentials-file: /home/piuser/.cloudflared/TUNNEL_UUID.json

ingress:
  - hostname: pi.vodun.cc
    service: http://localhost:80

  - hostname: node-red.vodun.cc
    service: http://localhost:1880

  - hostname: ssh.vodun.cc
    service: ssh://localhost:22

  - service: http_status:404

5. ตรวจสอบ Cloudflare Tunnel Configuration

cloudflared --config /etc/cloudflared/config.yml tunnel ingress validate

ควรได้:

OK

6. Restart Cloudflare Tunnel

sudo systemctl restart cloudflared

ตรวจสอบ:

systemctl status cloudflared --no-pager

ควรพบ:

Active: active (running)

7. ป้องกัน Node-RED ด้วย Cloudflare Access

ก่อนเปิด Editor ให้ผู้ใช้ภายนอก ต้องสร้าง Cloudflare Access application สำหรับ:

node-red.vodun.cc

ขั้นตอนใน Cloudflare Zero Trust Dashboard:

  1. ไปที่ Access → Applications และเพิ่ม application แบบ Self-hosted
  2. กำหนด hostname เป็น node-red.vodun.cc
  3. สร้าง policy แบบ Allow เฉพาะ email, email domain หรือกลุ่มผู้ใช้ที่อนุญาต
  4. หลีกเลี่ยง policy ที่อนุญาต Everyone สำหรับ Node-RED Editor
  5. บันทึกแล้วทดสอบด้วย Private/Incognito Window

ผู้ใช้ต้องผ่าน Cloudflare Access ก่อน แล้วจึง Login ด้วย Node-RED User Security อีกชั้นหนึ่ง อย่าเปิดใช้งานจาก Internet หากยังไม่มี Access policy

8. เปิด Node-RED จาก Internet

จาก Notebook / PC / Smartphone ที่อยู่นอก LAN เปิด Browser ไปที่:

https://node-red.vodun.cc

เส้นทางการเชื่อมต่อ:

9. ไม่ต้องทำ Port Forwarding

วิธีนี้ไม่ต้องเปิด 1880 → Internet ที่ Router และไม่ต้องตั้งค่า:

  • Port Forward
  • NAT rule
  • DDNS
  • Public IPv4

เพราะ Raspberry Pi เป็นฝ่ายสร้าง outbound connection ไปยัง Cloudflare

10. ตรวจสอบ Node-RED Service

ดูสถานะ:

systemctl status nodered.service --no-pager

ไฟล์นี้ใช้ตรวจว่า Node-RED พร้อมเป็น origin สำหรับ Cloudflare Tunnel เท่านั้น การติดตั้ง, restart หรือแก้ configuration ของ Node-RED ให้ทำใน Knowledge Base ของ Node-RED

11. ดู Log ของ Node-RED

ดู log ล่าสุด:

journalctl -u nodered.service -n 50 --no-pager

ดูแบบ Real-time:

journalctl -u nodered.service -f

12. ดู Log ของ Cloudflare Tunnel

journalctl -u cloudflared -n 50 --no-pager

Real-time:

journalctl -u cloudflared -f

13. Node-RED Security

เนื่องจาก Node-RED Editor เปิดให้เข้าจาก Internet ควรเปิด Authentication ของ Node-RED

ไฟล์ตั้งค่า: /home/piuser/.node-red/settings.js

ระบบ kathu ได้ตั้ง Node-RED User Security ไว้แล้ว:

รายการ ค่า
Username admin
Password รหัสผ่านที่ตั้งไว้ใน Node-RED

ดังนั้นผู้ที่ผ่าน Cloudflare Access และเปิด https://node-red.vodun.cc

ต้อง Login ด้วยบัญชี Node-RED อีกครั้งก่อนเข้า Editor การใช้ Access และ Node-RED Authentication ร่วมกันเป็นการป้องกันสองชั้น ไม่ควรปิดอย่างใดอย่างหนึ่ง
