SSH from Mac or Windows over Direct LAN

ก่อนหน้า: 16 - Python BLE Environment and Librariesกลับหน้าแรก
เครื่องที่ใช้ในตัวอย่าง

Raspberry Pi มี hostname เป็น kathu และ user เป็น piuser ชื่อเหล่านี้เป็นค่าที่ตั้งขึ้นสำหรับเครื่องตัวอย่าง ให้แทนด้วย hostname และ user ของเครื่องที่ใช้งานจริง

วิธีเข้าถึง Raspberry Pi จาก Mac หรือ Windows ผ่านสาย LAN โดยตรง เหมาะสำหรับทำงานแบบ headless โดยไม่ต้องต่อจอ คีย์บอร์ด หรือเมาส์กับ Raspberry Pi

Mac / Windows PC
   |
   | LAN cable
   v
Raspberry Pi: kathu
   |
   +-- SSH :22

1. ต่อสาย LAN

ต่อสาย LAN จาก Raspberry Pi เข้ากับ Mac หรือ Windows PC โดยตรง หากเครื่องไม่มีพอร์ต Ethernet ให้ใช้ USB Ethernet Adapter

2. เปิด SSH บน Raspberry Pi

ถ้ายังไม่ได้เปิด SSH ให้เข้า Raspberry Pi ผ่านจอและคีย์บอร์ดชั่วคราว แล้วรัน:

sudo raspi-config

เลือก Interface Options > SSH > Enable เมื่อเปิดแล้ว SSH server จะรับการเชื่อมต่อผ่าน TCP port 22

ตรวจสอบสถานะได้ด้วย:

systemctl status ssh --no-pager
ss -lnt | grep ':22'

3. เชื่อมต่อด้วยชื่อเครื่อง

macOS

เปิด Terminal แล้วรัน:

ssh piuser@kathu.local

Windows

เปิด Windows Terminal, PowerShell หรือ Command Prompt แล้วใช้คำสั่งเดียวกัน:

ssh piuser@kathu.local

ถ้าระบบแจ้งว่าไม่รู้จักคำสั่ง ssh ให้ติดตั้ง OpenSSH Client ที่

Settings > System > Optional features > View features

จากนั้นค้นหา OpenSSH Client แล้วติดตั้ง ก่อนเปิด Terminal ใหม่อีกครั้ง

ในการเชื่อมต่อครั้งแรก ให้ตรวจสอบ SSH host key ก่อนตอบรับ จากนั้นใส่รหัสผ่านของ user piuser บน Raspberry Pi

เมื่อเข้าได้แล้วจะเห็น prompt คล้ายตัวอย่าง:

piuser@kathu:~ $

ข้อความนี้หมายความว่า user ปัจจุบันคือ piuser และ hostname ของเครื่องคือ kathu

4. ถ้าเข้า kathu.local ไม่ได้

ชื่อที่ลงท้ายด้วย .local อาศัย mDNS หาก resolve ชื่อไม่ได้ ให้หา IP address ของ Raspberry Pi แล้วเชื่อมต่อด้วย IP แทน

ตรวจรายการอุปกรณ์ที่ Mac หรือ Windows เคยพบในเครือข่าย:

arp -a

บน Windows ตรวจการตั้งค่า IP ของ Ethernet adapter เพิ่มเติมได้ด้วย:

ipconfig
Get-NetIPAddress -AddressFamily IPv4

ถ้าเข้าถึง Terminal ของ Raspberry Pi ได้ ให้ตรวจ IP โดยตรง:

hostname -I
ip -br addr

จากนั้นเชื่อมต่อด้วย IP ที่อยู่บน Ethernet interface เช่น:

ssh piuser@192.168.x.x
NOTE

arp -a แสดงเฉพาะอุปกรณ์ใน ARP cache จึงอาจไม่พบ Raspberry Pi ที่ยังไม่เคยสื่อสารกับเครื่อง client

5. ถ้า Raspberry Pi ไม่ได้รับ IP จากสาย LAN

macOS: Internet Sharing

Mac สามารถแจก IP address ให้ Raspberry Pi ด้วย Internet Sharing:

  1. เปิด System Settings > General > Sharing > Internet Sharing
  2. ตั้ง Share your connection from เป็น Wi-Fi
  3. ตั้ง To computers using เป็น Ethernet หรือชื่อ USB Ethernet Adapter
  4. เปิด Internet Sharing แล้วรอให้ Raspberry Pi ขอ IP address

Windows: Internet Connection Sharing

Windows สามารถแจก IP address ให้ Raspberry Pi ด้วย Internet Connection Sharing (ICS):

  1. กด Win + R พิมพ์ ncpa.cpl แล้วกด Enter
  2. คลิกขวา adapter ที่เชื่อมต่อ Internet เช่น Wi-Fi แล้วเลือก Properties
  3. เปิดแท็บ Sharing
  4. เลือก Allow other network users to connect through this computer's Internet connection
  5. เลือก Ethernet adapter ที่ต่อกับ Raspberry Pi แล้วกด OK
  6. รอให้ Raspberry Pi ขอ IP address แล้วตรวจด้วย arp -a หรือ ipconfig

ชื่อเมนูและ adapter อาจต่างกันตาม Windows รุ่นและอุปกรณ์ที่ใช้ ไม่ควรกำหนด IP ของ Raspberry Pi เองจนกว่าจะตรวจ subnet ที่ ICS สร้างให้เรียบร้อย

จากนั้นลองเชื่อมต่อใหม่:

ssh piuser@kathu.local

หรือใช้ IP ที่ตรวจพบ:

ssh piuser@IP_ADDRESS
ตรวจ interface ก่อนแก้เครือข่าย

ถ้า Raspberry Pi เชื่อมทั้ง LAN และ Wi-Fi อาจมีหลาย IP address ให้ใช้ ip -br addr และ ip route เพื่อยืนยันว่า address ใดอยู่บน Ethernet interface

6. คำสั่งที่ใช้บ่อย

เข้า Raspberry Pi จาก Mac หรือ Windows:

ssh piuser@kathu.local

ตรวจ hostname และ IP บน Raspberry Pi:

hostname
hostname -I
ip -br addr

ดูอุปกรณ์ใน ARP cache จาก Mac หรือ Windows:

arp -a

ดู NetworkManager connection และลำดับความสำคัญบน Raspberry Pi:

nmcli connection show
nmcli -f NAME,AUTOCONNECT,AUTOCONNECT-PRIORITY connection show

7. สรุปค่าตัวอย่าง

ค่า ตัวอย่าง ความหมาย
User piuser บัญชีผู้ใช้บน Raspberry Pi
Hostname kathu ชื่อเครื่องที่ผู้ดูแลตั้งขึ้น
mDNS name kathu.local ชื่อสำหรับค้นหาเครื่องในเครือข่าย local
SSH port 22 port มาตรฐานของ SSH server

คำสั่งหลักของเครื่องตัวอย่างจึงเป็น:

ssh piuser@kathu.local
