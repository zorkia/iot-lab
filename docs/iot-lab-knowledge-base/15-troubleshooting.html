Troubleshooting

ก่อนหน้า: 14 - Mijia BTHome Decodeกลับหน้าแรกถัดไป: 16 - Python BLE Environment and Libraries

ตรวจจากชั้นที่ใกล้ service ที่สุดออกไปหา client:

Process/Service → Log → Listening Port → Localhost → LAN Client → Application Data

เปลี่ยนทีละจุดและทดสอบซ้ำ เพื่อให้รู้ว่าการแก้ใดทำให้ผลเปลี่ยน

Mosquitto

  • MQTT เข้าไม่ได้
  • Broker ไม่เริ่มหลังแก้ Config
  • Password file permission
  • Authentication failed / Anonymous access

Network / Wi-Fi

  • ตรวจว่าใช้ LAN หรือ Wi-Fi
  • สร้าง Wi-Fi Profile
  • แก้ Netplan และ Profile เก่า

Node-RED

  • Node-RED ไม่ขึ้น
  • Dashboard ไม่เปลี่ยน
  • เข้า Editor ไม่ได้

SQLite

  • SQLite ไม่มี Record
  • Statistics หายเป็นช่วง ๆ
  • สาเหตุ INSERT ทำค่า Statistics หาย

Bluetooth / BTHome

  • Bluetooth ขึ้น NotReady
  • BTHome packet มีข้อมูลไม่ครบ
  • Bluetooth Setup
