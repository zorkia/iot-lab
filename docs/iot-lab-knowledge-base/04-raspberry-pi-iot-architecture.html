ก่อนหน้า: 03 - Raspberry Pi Network and Wi-Fiกลับหน้าแรกถัดไป: 05 - Mosquitto MQTT Broker

Architecture Checkpoints

1. Communication

  • ESP32 หรือ Simulator Publish MQTT ได้
  • Mosquitto รับ Message ได้
  • Node-RED Subscribe Topic ถูกต้อง

2. Monitoring

  • Payload ถูกแปลงเป็น Number หรือ Object ตามที่ Node ต้องการ
  • Gauge แสดงค่าปัจจุบัน
  • Chart แยก Series ด้วย msg.topic

3. Storage และ Query

  • SQLite บันทึกเฉพาะข้อมูลที่ผ่าน Validation
  • ตรวจ INSERT ได้จาก command line
  • Query Historical Data และ Rolling Statistics ได้

4. Control

  • แยกโหมด MANUAL และ AUTO
  • มี Hysteresis หรือ Failsafe ตามชนิดระบบ
  • ตรวจ Actual State หลังส่ง Command

5. Reliability

  • แยก ONLINE/OFFLINE ออกจาก VALID/INVALID/STALE
  • Services เริ่มอัตโนมัติด้วย systemd
  • Local Operation ทำงานต่อได้เมื่อ Internet ล่ม
  • มี Backup, Recovery และ Fault Test

Component หน้าที่หลัก

Bluetooth Controller รับ BLE Advertisement
Python Gateway Decode, Normalize, Validate หรือแปลง Protocol

Node-RED ประมวลผล จัดเส้นทางข้อมูล และสร้าง Flow
FlowFuse Dashboard แสดง Current Value, Chart, Status และ Control UI
SQLite เก็บ Historical Data และ Control Log
systemd เริ่ม Service และ Restart Process เมื่อเกิด Failure
Cloudflare Tunnel เปิด Remote Access โดยไม่ทำ Port Forwarding

เส้นทางนี้เริ่มจากการอ่านและส่งข้อมูล ก่อนเพิ่มการจัดเก็บ การวิเคราะห์ การควบคุม Security และ Reliability แล้วจึงรวมทุกส่วนเป็น Mini Project ใน LAB 28

หลักการออกแบบสำหรับการเรียนรู้

  • ทดสอบทีละรอยต่อและหยุดแก้เมื่อชั้นนั้นทำงานแล้ว
  • ตรวจ BLE Raw Data ก่อน Decode และตรวจ MQTT ก่อนต่อ Node-RED
  • ตรวจ SQL INSERT ก่อนทำ Statistics หรือ History Chart
  • แยก Write Path, Read Path และ Control Path เพื่อให้ Debug ได้ง่าย
  • ใช้ข้อมูล Simulator ทดสอบ Flow ก่อนเชื่อม Sensor จริง
  • อย่าเพิ่ม Remote Access ก่อน Local Service ทำงานถูกต้อง
