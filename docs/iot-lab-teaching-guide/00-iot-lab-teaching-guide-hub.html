IoT Lab Teaching Guide - Hub

กลับหน้าแรกถัดไป: LAB 01 - ตรวจสอบระบบ Raspberry Pi

คู่มือปฏิบัติการ IoT Lab ฉบับเต็มสำหรับ Raspberry Pi kathu

ชื่อที่ใช้ในเอกสาร

`kathu` คือชื่อเครื่องที่ตั้งขึ้น `kathu` เป็น **hostname ที่ผู้ดูแลตั้งให้ Raspberry Pi เครื่องหลักของ Lab** ไม่ใช่ชื่อมาตรฐานของ Raspberry Pi และเครื่องอื่นสามารถใช้ hostname ต่างกันได้ ตรวจชื่อเครื่องปัจจุบันด้วยคำสั่ง `hostname`

คำที่คล้ายกันในเอกสารมีความหมายต่างกัน:

ค่า ความหมาย
kathu hostname ของ Raspberry Pi เครื่องหลัก
Tunnel kathu ชื่อ Cloudflare Tunnel ที่ตั้งให้เหมือน hostname เพื่อให้จำง่าย แต่สามารถใช้ชื่ออื่นได้
pi.vodun.cc public hostname สำหรับ Web Server
node-red.vodun.cc public hostname สำหรับ Node-RED
ssh.vodun.cc public hostname สำหรับ SSH
192.168.1.50 IP address ตัวอย่างภายใน LAN ของเครื่อง kathu; ค่าจริงอาจเปลี่ยนเมื่อได้รับค่าใหม่จาก DHCP

ถ้าใช้ Raspberry Pi เครื่องอื่น ให้แทน kathu, 192.168.1.50, Tunnel name และ public hostname ด้วยค่าของเครื่องนั้น โดยตรวจ hostname และ IP ด้วย:

hostname
hostname -I

      ↓

      ↓

      ↓

      ↓

      ↓

      ↓

      ↓

      ↓

      ↓

Architecture ปัจจุบัน

ESP32 / Sensor / Simulator
        |
        | MQTT :1883
        | Username: iotuser
        v
+--------------------------------------+
| Raspberry Pi "kathu"                 |
|                                      |
| Mosquitto :1883                      |
|      |                               |
|      v                               |
| Node-RED :1880 ---> SQLite           |
+--------------------------------------+
        |
        | Cloudflare Tunnel
        +--> node-red.vodun.cc
        +--> ssh.vodun.cc

Raspberry Pi → Mosquitto MQTT → Node-RED → FlowFuse Dashboard → SQLite → Mijia LYWSD03MMC/BTHome

สถานะเอกสาร: รวบรวมจากลำดับที่ทดลองจริงในแล็บนี้ โดยเก็บทั้งคำสั่ง, Flow, SQL, จุดตรวจสอบ, ปัญหาที่พบ และแนวทางแก้

  • เครื่องหลัก: Raspberry Pi kathu, user piuser
  • IP ของ Raspberry Pi: ตัวอย่างใช้ 192.168.1.50; ให้ตรวจค่าจริงด้วย hostname -I ก่อนรันคำสั่งของแล็บ
  • Node-RED: 5.0.7
  • Node.js: 22.23.2
  • Python: 3.13.5
  • Python venv: /home/piuser/iot-venv
  • SQLite DB: /home/piuser/iot.db
  • MQTT Broker: Mosquitto 2.0.21
  • MQTT account สำหรับ Lab: username iotuser / password ที่ผู้สอนกำหนด
192.168.1.50 เป็น IP ตัวอย่างของ Raspberry Pi kathu ใน LAN ให้ตรวจ IP ปัจจุบันด้วย hostname -I เพราะ DHCP อาจกำหนด address ค่าใหม่ให้เครื่อง
