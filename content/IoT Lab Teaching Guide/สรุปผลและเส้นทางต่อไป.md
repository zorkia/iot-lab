## Architecture checkpoint หลังจบ MQTT/Database

จบช่วง MQTT/Database ที่:

```text
ESP32 / Simulator
       |
       | MQTT
       v
   Mosquitto
       |
       v
    Node-RED
       |
       +------------→ Gauge
       |
       +------------→ Real-time Chart
       |
       +------------→ SQLite WRITE
                          |
                          v
                        iot.db
                          ^
                          |
                    SQLite STAT
                          ^
                          |
                   AVG/MIN/MAX
                    last 5 min
```

แนวคิดที่นักศึกษาได้:

```text
Monitoring
Storage
Query
Statistics
Time Window
```

## แผนต่อยอดหลังจบช่วง MQTT / Database

หัวข้อถัดไปควรต่อยอดจากระบบ MQTT, Dashboard, SQLite และ Statistics ก่อนข้ามไป BLE
เพื่อให้นักศึกษาเห็นเส้นทางจาก monitoring ไปสู่ control และ reliability ชัดขึ้น

Core Series `LAB 01–28` ครบชุดแล้ว โดย LAB 28 เป็น Integrated IoT Mini Project สำหรับรวมระบบทั้งหมด
ก่อนแยกหัวข้อขั้นสูงออกเป็น Advanced IoT Lab Series

หลังจบช่วงปัจจุบัน นักศึกษาควรอธิบาย Data Flow ได้สองแบบ

## MQTT / Wi-Fi

```text
Sensor/Simulator
      ↓
JSON
      ↓
MQTT Publish
      ↓
Mosquitto
      ↓
Node-RED
      ├──→ Gauge
      ├──→ Real-time Chart
      └──→ SQLite
                ↓
          SQL Statistics
```

## BTHome / BLE

```text
Mijia
  ↓
BLE Advertisement
  ↓
Raspberry Pi hci0
  ↓
Bleak
  ↓
bthome-ble
  ↓
temp / humi / batt
```

## จุดหยุดของเอกสารฉบับปัจจุบัน

สำหรับ Mijia/BTHome ปัจจุบันทำถึง:

```text
หลาย Mijia
   ↓
BTHome Advertisement
   ↓
Raspberry Pi
   ↓
Decode
   ↓
แสดง temp / humi / batt แยกตาม MAC
```

ยังไม่ต่อ BTHome → MQTT → Node-RED เพราะต้องตรวจการอ่านหลายอุปกรณ์ให้ถูกต้อง
และนิ่งก่อนตามลำดับการทดลอง

## เส้นทางการสอนต่อจากนี้

หลัง MQTT → Node-RED → Dashboard → Real-time Chart → SQLite → SQL Statistics:

```text
Rule / Alert Processing
        ↓
Manual Control ผ่าน MQTT
        ↓
Automatic Control
        ↓
MQTT Topic Design สำหรับหลายอุปกรณ์
        ↓
Multi-device Dashboard
        ↓
Data Quality / Device Offline
        ↓
Mini Project
```

ระดับถัดไปค่อยเพิ่ม:

```text
Cloud
Internet Access
TLS / ACL / Advanced Security
Remote Monitoring
```

ไม่ควรนำมาปนกับ Lab พื้นฐานเร็วเกินไป
